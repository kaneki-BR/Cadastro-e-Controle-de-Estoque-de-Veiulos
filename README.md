# Cadastro-e-Controle-de-Estoque-de-Veiulos
Sistema de Controle de Estoque de Veículos desenvolvido em ASP.NET Core MVC (.NET 8) para o desafio técnico da Revemar. Oferece CRUD completo de veículos com persistência em banco Oracle Database via EF Core 8, arquitetura limpa em 3 camadas (Domain, Infrastructure e Web) e interface moderna e responsiva utilizando Bootstrap 5.
